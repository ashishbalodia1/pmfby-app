# KrisiBandhu Website Assets

This directory contains images and assets for the KrisiBandhu website.

## Image Requirements

### Directory Structure
- `/images/` - Main images folder
  - `background.png` - Hero section background
  - `farmer-with-phone.jpg` - About section image
  - `google-play-badge.png` - Google Play Store download badge
  - `app-store-badge.png` - Apple App Store download badge

### Image Specifications

#### Hero Background (background.png)
- Dimensions: 1920x1080px
- Format: PNG or JPG
- Content: Agricultural field or farmland
- Style: High quality, vibrant colors

#### About Section Image (farmer-with-phone.jpg)
- Dimensions: 800x600px
- Format: JPG
- Content: Farmer using smartphone in field
- Style: Professional, clear, optimistic

#### App Store Badges
- Download from official sources:
  - Google Play: https://play.google.com/intl/en_us/badges/
  - App Store: https://developer.apple.com/app-store/marketing/guidelines/

### Placeholder Images

For development, you can use placeholder images from:
- Unsplash: https://unsplash.com/s/photos/farmer
- Pexels: https://www.pexels.com/search/agriculture/
- Placeholder services: https://via.placeholder.com/

### Optimization

All images should be optimized for web:
- Compress images using tools like TinyPNG or ImageOptim
- Use WebP format for better compression (with fallbacks)
- Implement lazy loading for better performance
- Use responsive images with srcset for different screen sizes
