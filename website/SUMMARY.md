## 💡 Usage Tips

### Customization
1. **Colors**: Edit CSS variables in `css/styles.css` (line 6-14)
2. **Content**: Edit text directly in `index.html`
3. **Images**: Replace files in `images/` folder
4. **Contact**: Update info starting at line 215 in `index.html`

### Testing
```bash

cd website
python3 -m http.server 8000
# Open http://localhost:8000
```

### Deployment
```bash
# Easiest: Drag & drop to Netlify
# Or use CLI:
netlify deploy --prod
```
